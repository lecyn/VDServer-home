# 开始之前

欢迎来到 **Vanora Dynamo** —— 一个纯原版基岩版生电服务器。本页将带你完成从入服到上手的第一步。

## 1. 加入服务器

1. 先在 [文档](/) 中查看 **教程 > 下载**，获取适配你设备的基岩版客户端。
2. 若你是手机端需要特殊版本，可参考 **教程 > 改包**。
3. 启动游戏，在「服务器」列表中添加服务器地址（地址请咨询群内管理员）。
4. 由于服务器开启了白名单，请先在交流群提交入服申请，审核通过后即可进入。

## 2. 社群公约

我们主打「小而和谐」的社群氛围，唯一公约是 **尊重互助**：

- 拒绝熊孩子行为，备份保护机制保障。
- 鼓励生电玩法：红石机械、自动化农场皆可自由搭建。
- 不定期摆烂

> 遇到问题？随时在交流群 @管理员，我们同为学生的管理团队会及时响应。
